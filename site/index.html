Charter Live on Base mainnet

Rent a machine from someone's home. Pay per 30 seconds, from a browser wallet.

Charter is a compute marketplace on TOON. A host lists a machine behind a hidden node and names a price. A renter picks it, pays one interval at a time in USDC on Base, and gets the output back. No account on either side.

Rent a machine See the receipts

The storefront runs on the operator's own node, so your wallet will warn about an unfamiliar site. The one signature it asks for is a USDC deposit into an x402 channel on Base, explained below.

What you get

A machine, by the intervalA container on the host's machine for as long as you keep paying. Stop paying and it ends. If it never boots, nothing is owed.
Two jobs todayRun your own Python script (NumPy, no network, sandboxed under gVisor), or fetch pages through an anonymous exit and get back text and a screenshot of each.
Hidden on both sidesThe host is a hidden service with no domain and no open port. The renter is a wallet. Neither learns the other's IP.
One signature, not sixtyYour wallet signs once to deposit at least 0.10 USDC into a payment channel. Every interval after that is a voucher the page signs silently. What you do not use comes back when the lease ends.

How a lease runs

  1. The host runs a TOON node at home and publishes an offer: CPU, memory, interval price, which jobs it runs.
  2. The storefront lists the offer. You connect a wallet holding USDC on Base and click Rent.
  3. Your wallet signs one deposit into a batch-settlement channel on the x402 contract. The storefront opens the lease on the host and starts the clock.
  4. Every 30 seconds the page signs a cumulative voucher. The storefront checks it and pays the host the same interval over TOON, from its own channel. It never holds more than one interval of your money.
  5. The job finishes or you stop. The host's vouchers land on chain in a batch. The storefront claims yours, settles to the operator, and refunds the rest of your deposit.

Underneath: ILP routes every packet between the storefront and the host, and x402 channels settle them. Charter reuses that network rather than running its own payments. A renter who already runs a TOON node can skip the storefront and pay the host directly from the command line. An agent can do the same: the Charter repository ships a Claude Code skill that reads the offers, opens a lease and pays it by the interval with the toon CLI.

What this is not yet. One host, the founder's machine. The renters so far are the two founders. The storefront is at a raw address until it gets a domain. Lease state and output are per host; there is no marketplace fee, no reputation, no SLA. This page exists so the next host and the next renter can see exactly where things stand.

For hosts

Any machine behind a TOON node can list. Install the node, add three paid apps (open, tick, status), point them at the Charter host service, publish an offer. The storefront lists offers only from hosts the operator has added by hand, which is the whole vetting process today. The code is MIT; the commands are in its README.
