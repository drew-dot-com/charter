Privacy policy

Last updated 26 November 2026

Charter rents machines by the hour and is run by Drew Pierson. This page says what Charter keeps when you use it.

What Charter keeps

  • Payments. The wallet address that paid for a lease, what it paid and when. These payments are public on Base in any case.
  • Leases. The lease id, the job you sent (a script or a list of pages), and a copy of a finished job's output.
  • SSH public keys. The keys you give for a home. The host keeps them; Charter's storefront keeps them too if you ask for a grant or a monthly allowance.
  • Grant pitches. Your name, pitch and optional link, with the decision and its reason, are public at /grants. The pitch is sent to a model run by Google to be judged.
  • Monthly allowances. The account address that approved the allowance and the permission it signed.
  • Receipts. A hash of an output, never the output itself.
  • A request log. The time, the path, the answer code, the user agent and the referring site's name. It does not hold your IP address, the query or the body, and it is overwritten as it fills.

IP addresses

The storefront uses your IP address in memory to limit request rates and does not write it to disk.

X

Charter's X account names nobody who has not asked. If you opt in by posting your code, Charter keeps your X handle next to the wallet that paid. Post the same line with the word stop to undo it. The account also reads public posts about renting compute so its operator can reply, and keeps the text of posts it considered.

What Charter does not control

Hosts are run by independent operators. A host's operator can read a home's disk and the scripts you send, and sees the address you connect from over SSH. If you pin a file, the pinning service holds it and it is public.

What Charter does not do

No cookies, no trackers, no advertising, and no selling or sharing of data.

Copies

The storefront's records are backed up nightly to a machine the operator controls.

Removing your data

Write to the address below. Payments on Base cannot be removed by anyone.

Changes

If Charter starts keeping anything not listed here, this page changes first and the date at the top changes with it.
